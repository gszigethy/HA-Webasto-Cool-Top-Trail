# IR captures

This directory holds infrared evidence. The [baseline corpus](baseline/README.md)
contains 31 pulse arrays imported from the user's ESPHome YAML, not newly
recorded receiver captures. New sessions must retain their own metadata.

The [first live ON/OFF session](live/2026-10-13-on-off/README.md) contains two
user-labelled, checksum-valid GPIO32 receiver captures at cool/auto/22 C.

Follow [the capture procedure](../docs/ir-capture.md). Include hardware/firmware
metadata and the remote's before/after settings alongside each session.
